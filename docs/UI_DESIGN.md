# 图迹 UI 设计稿交付说明

可以用 Photoshop 设计主界面和其他页面，再由程序实现可操作的控件、布局与状态。静态效果图用于确认视觉，交互说明用于确定行为。

## 首轮需要提供

| 内容 | 建议格式 | 用途 |
| --- | --- | --- |
| 主界面与各页面效果图 | 每个页面/画板导出 PNG，保持原始尺寸 | 确认整体布局、颜色、间距和效果，不依赖 PSD 能否完整渲染 |
| 分层设计稿 | PSD；图层分组命名清楚，尽量保留可编辑文字 | 提取尺寸与样式、确认细节。只有草图或 PNG 也能先做基础版本 |
| 窗口规格 | 文字说明，例如 1440×900、允许缩放、最小窗口大小 | 决定如何适应不同屏幕与 Windows 缩放比例 |
| 操作说明 | 文字、标注图或简单连线 | 每个按钮的作用、弹窗内容、页面跳转、搜索结果展示方式 |

优先设计“首次打开/空素材库”和“有检索结果”两种主界面状态。扫描中、无结果、读取失败、设置/弹窗如需指定样式，也请提供参考；未设计的状态可以按主界面风格补齐。按钮选中、禁用、悬停等特殊效果可以通过标注说明，不需要每个控件都单独画一张图。

## 如果使用了自定义素材，请一并提供

- Logo、应用图标、按钮图标：优先 SVG 或透明 PNG；Windows 应用图标可另给 ICO。透明 PNG 建议提供足够分辨率，避免只能从合成图中截取。
- 背景、插画、装饰和示例缩略图：提供对应的独立图片；如是链接智能对象，附上源资源或改为嵌入。
- 字体：字体名称、字重；需要自带字体时提供可用于该项目的字体文件（OTF/TTF）。无法提供时可指定替代字体。
- 色值、字号、圆角、间距：可以在 PSD 或一张样式说明图中标注。

普通按钮、文本、输入框、表格、滚动条通常用代码实现，不必全部切图。提供设计用的示例内容即可，不需要上传整个公司素材库。

## 多画板问题的实际回归样本

为了验证具体 Photoshop 文档的字体、蒙版、智能对象和图层效果，可以另外提供一个可分享或脱敏的多画板 PSD/PSB，以及其中应当被检索命中的画板导出 PNG/JPG，并注明对应画板名称。程序生成样本已覆盖基本格式与索引流程，不能代替对每一种 Adobe 特性的实际文件验证。

当前项目是桌面程序。设计稿可以用于更新现有桌面 UI；如果希望转为“本机后台＋浏览器”的使用方式，需要同时说明，网页界面属于另一项实现工作。
