图迹 Windows 64 位安装包，适用于 Windows 10/11。

下载 `ImageTools-版本号-win-x64-setup.exe`，双击按中文向导安装。无需另装 Python，安装后可离线进行整图、局部截图及设计源文件候选检索。

- 中文安装向导，桌面和开始菜单快捷方式，Windows 系统卸载入口。
- 当前用户安装，无需管理员权限。
- 直接运行新版安装包即可升级。升级、卸载和重新安装均保留 `%LOCALAPPDATA%\ImageTools` 中的现有索引及缩略图，也不会删除原素材文件。
- 内置 Python、Qt、图像处理、PSD/PSB 和 PDF 渲染依赖。EPS / 旧版 PostScript AI 的 Ghostscript 仍是可选外部组件。

安装包只有在 Windows 构建、应用回归、旧版升级、已安装 EXE 功能检查、卸载和重装检查成功后才会由工作流发布。Windows 公司共享盘、实际大型素材库及特定 Adobe 文档需按实际环境验收。

附件 `.sha256` 为安装文件 SHA-256 校验值。本安装包暂未做商业代码签名，Windows 可能提示未知发布者。
