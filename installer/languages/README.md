obtained from the official Inno Setup source repository at release `is-6_7_4`:

- Commit: `c2913c993858a781fcb455bac8b8949c1c366cb8`

The translation targets Inno Setup 6.5+. It is checked in because it is not
included with the Inno Setup 6.7.4 compiler installer. Building an installer
requires no language-file downloads. Preserve the attribution and license when
updating this file, and verify the new source and checksum before use.
